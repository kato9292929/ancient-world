# アトランティス（伝説の都）

プラトン『クリティアス』の記述をもとにした**想像図**。図面（DXF）と、それを元にした Blender の動画（音つき）。
外部の素材・API キーは使わず、図面・巻物の絵・3D・音をすべて Python で作る。

寸法の元は 1 か所（[`plan.py`](plan.py)）にまとめ、図面・巻物・3D・音の合図がすべてそこを読む。
1 スタディオン = 185m、1 プレトロン = 30.8m、1 フィート = 0.31m として換算した。

## 作るもの

| 種類 | 中身 | 作る所 |
|---|---|---|
| DXF（A2、mm、表題欄・特記事項つき） | AT-01 配置図／AT-02 中央島及び内環 平面図／AT-03 ポセイドン神殿 平面図・南立面図・東立面図／AT-04 貨幣 表・裏 | `drawings/make_dxf.py` |
| 巻物の絵 | 羊皮紙にセピアのインクで描いた配置図。題字の飾り枠（ATLANTIS）・方位盤・雷文の縁。インクだけのマスク（光らせる用）も書く | `drawings/parchment.py` |
| 3D シーン | 都・神殿・海・山・市街・港・櫂船・カメラ・タイトル・エンドカード | `scene/` |
| 音 | リラ・アウロス・枠太鼓・合唱（ニのドリア旋法）と効果音 | `audio/synth.py` |
| 動画 | 1920×1080、24fps、20 秒（本編 18 秒＋ロゴのエンドカード 2 秒）、MP4 | `make.py` |

## 進行（24fps、`plan.CUES`）

| 秒 | 場面 |
|---|---|
| 0–1.3 | 巻物が上（北）から広がり、配置図が現れる（冒頭 1 秒は切って、広がり始めた所から入る） |
| 1–2.4 | 封蝋と貨幣が退き、インクが光り、線が光のワイヤーフレームとして立ち上がる |
| 3–7.5 | 中央島と陸の環 → 城壁と塔 → 橋 → 兵舎・王宮・円形神殿・柱廊・競馬場 → 庭木 |
| 7.5–11.2 | ポセイドン神殿: 基壇 → 柱を一本ずつ → 屋根 → 金の飾り。線は実体に吸収されて消える。三叉の矛の柱越しに見上げるカット |
| 11.2–14.5 | 巻物が消え、海が満ちて水の環が光る。北の山並みがせり上がり、市街とオリーブ畑が外へ広がる。篝火と灯台がともり、三段櫂船が船台から水に降りる |
| 14.5–18 | 運河の沖から、同心円の都と夕焼けの空。櫂船が運河を進む。タイトル「アトランティス／ATLANTIS／海の彼方に、ポセイドンの都があった」 |
| 18–20 | ロゴのエンドカード（黒地に柔らかく現れ、光の筋が走ってフェードアウト） |

## 記述どおりの所と、想像で補った所

| 記述どおり（『クリティアス』） | 想像で補った所（特記事項にも書いた） |
|---|---|
| 中央島 径 5 スタディオン、水の環 3 重・陸の環 2 重（幅 1・2・2・3・3） | 橋の方位（東西南北の 4 本）、塔の数と高さ、城壁の高さ |
| 大運河 幅 3 プレトロン・深さ 100 フィート・長さ 50 スタディオン | 3D では運河を 1.4km に縮めた（50 スタディオンだと都が点になる）。図面は省略線で実長を書いた |
| 城壁を外から青銅・錫・オリハルコンで覆う。石は白・黒・赤 | 石の色の配分（白を基調に控えめに混ぜた） |
| 神殿 長さ 1 スタディオン×幅 3 プレトロン、銀張り、オリハルコン、金の飾り | 神殿の高さ・柱の数（周柱 10×19）・屋根の形 |
| 黄金の囲い、王宮、温泉と冷泉、競馬場、兵舎、港と船台 | それぞれの位置と大きさ。円形神殿・柱廊・外港の灯台・三叉の矛の記念柱は演出 |
| 北に山、南に平野、平野の灌漑水路 | 市街は環から 1.7km で切った（外壁は環から 50 スタディオン。図面の小図に示した） |
| — | **貨幣は創作**。『クリティアス』に貨幣の記述は無く、鋳造貨幣の出現（前 7 世紀頃）は伝説の年代と合わない |

## 指定から変えた点

- **図面の縮尺**: 記述どおりの寸法だと、指定の縮尺（配置図 1:2500、中央島 1:1000、神殿 1:300）は A2 に収まらない
  （例: 神殿の長さ 185m は 1:300 で 617mm）。寸法を変えずに、収まる縮尺にした
  — 配置図 **1:20000**（小図 1:150000）、中央島及び内環 **1:6000**、神殿 **1:600**、貨幣 2:1
- **Blender のバージョン**: 4.2 の指定に対し、この環境の Python 3.13 で動く `bpy` 5.2 を使った。
  スクリプトは 5.x の API（ジオメトリノードの入力、slotted action）に合わせてある
- **図面を 4 枚にした**: 貨幣の図（AT-04）を追加

## 動かし方

```bash
python3.13 -m venv .venv && .venv/bin/pip install -r packages/aw-world/atlantis/requirements.txt
# 和文の明朝体（無ければ図面と動画の和文が代替フォントになる）
sudo apt-get install fonts-ipafont-mincho

cd packages/aw-world
../../.venv/bin/python atlantis/make.py assets            # DXF・巻物の絵・音
../../.venv/bin/python atlantis/make.py scene             # out/atlantis/atlantis.blend
../../.venv/bin/python atlantis/make.py stills 16,250,425 # テスト静止画と 1 枚あたりの時間
../../.venv/bin/python atlantis/make.py estimate          # 本番の所要時間の見積もり
../../.venv/bin/python atlantis/make.py render            # 本番（少しずつ描いて休む。止めても続きから）
../../.venv/bin/python atlantis/make.py video             # out/atlantis/atlantis.mp4
```

**負荷の抑え方**: Blender は常に 1 本だけ。`nice 19`（低い優先度）、3 スレッド、24 フレームごとに 20 秒休む。
サンプル数は 8（＋デノイズ）。16 と見比べて差が見えなかったため。

描画は Cycles の CPU。EEVEE は GPU の無い環境ではソフトウェアの OpenGL でしか動かず、何も置かないシーンでも 1 枚 57 秒かかったため使っていない。
