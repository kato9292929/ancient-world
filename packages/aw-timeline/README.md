# aw-timeline

前1万年から現在までを縦に貫く年表。スクロール量と年代を連動させる。

データは `@aw/data` の `events.json` と `sites.json` を参照する。**座標は使わない。** そのため
座標が未取得でも完成できる。5 本のうちこれだけは aw-data の座標取得を待たない。

## 尺度：案A（線形固定）

前1万年から現在までを**均等（線形）**に取る。縮尺は一定で、断りなく変えない。

今のデータは 前1万年〜前54年 に集中していて、前1000年以降がほとんど無い。案A ではその区間が
**空白として見える**。それをそのまま見せる。可変尺度（案B）は採らない — 年代の誤読を扱う題材で、
自分の年表の縮尺が動くのは筋が悪く、読者が縮尺を誤読するリスクも残るため。

空白は将来のデータで埋まる（青銅器時代の崩壊で前1200年、エノク書・デンデラで前300年〜前54年 など）。
今は空でよい。

左の年代目盛りが定義域全体（前1万年〜現在）を 1000 年ごとに刻むので、後半に出来事が無いことが
目盛りの側でも見える。

## 静的優先・軽量

- **JavaScript を切っても、年代順に並んだ静的な一覧として全項目が読める。** HTML に全出来事を
  埋め込んでビルドする（`scripts/build.ts`）。
- スクロール連動（左の年代表示の追従・入場アニメーション）は **IntersectionObserver と CSS のみ**
  の上乗せ。重いライブラリは持ち込まない。
- **外部フォント CDN に依存しない。** システムフォントのスタックで組む。
- `prefers-reduced-motion: reduce` でアニメーションを止め、全項目を最初から表示する。
- JS 無効時は「表示中の年代」バッジを隠す（動かないものを出して誤読させない）。

## 出来事の表示

- 各出来事は 年代・見出し・1〜2文の説明・関連地点の id 配列 を持つ。
- **年代の但し書き（「頃」「以降」など）を落とさない。** 数値の隣に添える。
- **幅のある年代は幅（band）として描く。点にしない。**
- **`era_status: "unfetched"` の項目は年表に出さない。** 位置を推測して置かない。除外した件数は
  ヘッダに注記する。
- 関連地点があれば名称を出し、aw-map の `?site=<id>` にリンクする。
- `article_url` があれば記事へのリンクを出す。null なら出さない。

## ビルド

```bash
pnpm --filter @aw/timeline build     # dist/index.html を書き出す
```

`dist/index.html` は単一の静的 HTML（CSS と上乗せ JS を内包、外部依存なし）。

### aw-map へのリンク先

関連地点リンクは aw-map のデプロイ先を指す。aw-map は別プロジェクトとしてデプロイできるため、
base を環境変数で渡す:

```bash
AW_MAP_BASE=https://<aw-map のURL>/ pnpm --filter @aw/timeline build
```

未指定なら `/`（同一オリジンに aw-map を置く場合）。

## テスト

```bash
pnpm --filter @aw/timeline test
```

尺度と整形（`src/scale.ts`）と HTML 生成（`src/render.ts`）を単体テストで検証している。案A の
線形位置、但し書きの保持、幅→band、unfetched の除外、関連地点リンク、JS 無効時の構造、HTML
エスケープを含む。

## デプロイ（Vercel）

モノレポだが、このパッケージは単体でデプロイできる。Vercel のプロジェクト設定で:

- Root Directory: `packages/aw-timeline`
- Build Command: `pnpm --filter @aw/timeline build`（リポジトリルートからの依存解決のため、
  Install Command はルートで `pnpm install`）
- Output Directory: `dist`
